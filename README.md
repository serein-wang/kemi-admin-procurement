## 边界（硬）

- **选型：** 承载 A 为可嵌入模块（身份用 KEMI OIDC 网页授权码）；外围 D（erp-pro **仅**入库/料号协同，阶段 1 为 stub）；**C 金蝶回写不做**
- **宿主：** 页面、OIDC 回调、状态机都在本仓独立运行。不调用、不臆造 KEMI One / Canvas API。日后嵌入只通过 `registerAdminProcurement`
- **erp-pro：** 禁止混用生产料号审核会话；与生产轨隔离；stub 不接收 cookie
- **MaterialCodeNaming：** 仅当行政物资需料号时引用；本包不定义料号全文
- 金额阈值一律用占位符，**不编造数字**；仓库默认空值，测试夹具不算业务阈值
- 以 `docs/00`「最终措辞」为准（Q5 强制事前）
- 行政采购 ≠ 生产物料 / 金蝶生产采购订单
- 凭据只走环境变量，不进仓库
