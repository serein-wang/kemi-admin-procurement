### 边界（硬）

- **erp-pro：** 只做行政物资入库与料号协同；**禁止**混用生产料号审核会话（与 ErpAuditKit / 生产轨会话隔离）。
- **MaterialCodeNaming：** **仅当**行政物资需要料号时引用命名规范；本系统不定义料号规则全文。
- **金蝶 C：** 本期不做回写；若二期开启，须与生产采购单据隔离，且不替代 KEMI One 内审批。
- 行政采购流程本体是可嵌入模块（选型 A）。erp-pro 为外围协同，不是第二套审批系统。宿主 API 不在本模块调用面内。
