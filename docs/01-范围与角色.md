# 01 · 范围与角色

## 1. 产品定位

在 **KEMI One** 实现**非生产行政采购**协同：请购 → 审批 →（比价）→ 行政 PO → 收货/固资或费用化 → 发票与三单匹配 → 付款；以及员工垫付报销。深圳 CNY、香港 HKD。

源稿页眉曾：**待讨论未开发**；页脚：**未改 KEMI One / Canvas · 定稿后再开发**。

**选型已定（2026-11-06）：** 承载 **A** 嵌入 KEMI One/Canvas；外围 **D** erp-pro 仅入库/料号协同；**C** 金蝶回写本期未选（二期可再开）。MaterialCodeNaming 仅需料号时引用；**禁止**混用生产料号审核会话。

## 2. 在范围

- 路径①公司采购主流程 ①-1 … ①-13（含货到付款 / 月结）
- 路径①先款后货预付子流程 ①-P1 … ①-P10
- 预付超期例外 ①-E1 … ①-E3b
- 路径②员工垫付报销 ②-1 … ②-8（v3 无结构性变更）
- SoD S1–S5；审批矩阵骨架（阈值占位）
- 单据与状态机**草案**（见 docs/06）

## 3. 不在范围

- 生产物料采购、委外加工、金蝶生产采购订单替代
- erp-pro 料号审核、Redmine A1.2 / ECN / 签样主流程
- 编造金额阈值或会计科目明细
- Spec 定稿前的 KEMI One / Canvas 代码变更
- 凭据、账套密钥、银行接口密钥

## 4. 角色（泳道）

| 角色 | 路径①主流程 | 预付子流程 | 路径② |
|------|-------------|------------|--------|
| 申请人 | ①-1 请购；①-7 收货验收 | （通常非预付申请人） | ②-1/③ 垫付；②-4 报销 |
| 部门负责人 | ①-2 | ①-P2 | ②-2（若启用）；②-5 |
| 行政专员 | ①-5 比价；①-6 下 PO；①-8a/b；①-11 付款申请 | **预付申请人** ①-P1；①-E2 跟催；①-E3 | — |
| 财务负责人/会计 | ①-3 加签；①-9 发票；①-10 匹配；①-12 付款审批；记账 | ①-P3；①-P5；①-P7；①-P8；①-E1 | ②-6 审票；②-7 加签 |
| 总经理 | ①-4 | ①-P4 | （超额时视矩阵，源稿②-7「必要时上总经理」） |
| 出纳 | ①-13 付款 | ①-P6；①-E3b；尾款经 ①-13 | ②-8 打款 |

## 5. 公司 / 币种维度

- 业务实体字段建议：`company_code`（如 SZ / HK）、`currency`（CNY / HKD）
- 审批阈值按币种配置表读取（见 docs/05）
- 港深矩阵是否同构 → 开放问题 Q4

## 6. 与周边边界（例子先于规则）

**例子：** 研发要买示波器（办公/测试设备，非 BOM 生产料）→ 走本行政采购路径①。  
**例子：** PCBA 贴片用电阻电容 → **不走**本系统，走生产采购 / 金蝶 / erp-pro 料号轨。

**规则：** 标的物属性 `procurement_class = admin_non_production`；若误选生产类，应拒绝或导流（导流策略待产品定，本 Spec 只要求可区分）。

## 7. 源稿忠实性

步骤编号、负责岗位、SoD 标记以讨论稿 v3 步骤对照表为准；本包仅补充**建议默认**与**实现所需的状态/字段草案**，并显式标注建议。
